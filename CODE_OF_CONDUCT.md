# Código de Conduta

Este projeto segue o Contributor Covenant versão 2.0 para garantir um ambiente acolhedor e inclusivo.

## Nosso Compromisso

Queremos criar um espaço onde todos se sintam bem-vindos.  
Seja respeitoso, evite linguagem abusiva e tenha empatia pelas diferentes experiências de cada pessoa.

## Como Reportar

Se você testemunhar ou for alvo de comportamento inapropriado:
- Abra uma issue com a label `security` ou `question`  
- Envie um e-mail para os mantenedores: maintainers@omnicast.org

## Aplicação

Mantenedores poderão remover comentários, suspender ou banir participantes que violem essas diretrizes.

Para mais detalhes, leia o texto completo em  
https://www.contributor-covenant.org/version/2/0/code_of_conduct/
